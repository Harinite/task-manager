# Менеджер задач на Java

Консольное приложение для управления задачами.

## Возможности
- Добавление задач с приоритетом
- Отметка выполненных
- Удаление по названию
- Поиск по слову
- Статистика
- Цветной вывод в консоль

## Технологии
- Java
- Stream API
- PriorityQueue, Comparable
